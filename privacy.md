# Privacy Policy for Ingrid Health

Last updated: September 12, 2026

## Purpose

Ingrid Health is a private, non-commercial integration used by its owner to retrieve and analyze her own Google Health data.

## Google user data accessed

The application requests only these read-only Google Health permissions:

- Activity and fitness data
- Health metrics and measurements

Depending on availability, this can include steps, workouts, active-zone minutes, heart rate, resting heart rate, heart-rate variability, and related health metrics.

## Use of data

The data is used solely to provide personal retrieval, summaries, comparisons, and analysis requested by the authorized user.

Ingrid Health does not use Google user data for advertising, marketing, credit decisions, or user profiling unrelated to the requested personal health analysis.

## Storage and processing

OAuth credentials and retrieved health data are stored locally in the owner's private Hermes workspace and are not published in this repository.

When the owner explicitly requests AI-assisted analysis, selected values or summaries may be processed by the AI model provider configured in that workspace. Raw credential files and OAuth tokens are never sent for AI analysis.

## Sharing

Google user data is not sold. It is not shared with advertisers, data brokers, or unrelated third parties.

## Retention and deletion

Locally cached health data can be deleted by the owner at any time. Access can be revoked through the Google Account permissions page.

## Security

The integration uses OAuth 2.0, requests the minimum required read-only scopes, and stores OAuth credentials in private local files.

## Google API Services User Data Policy

Ingrid Health's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Contact

Questions about this private application can be submitted through the GitHub repository that hosts this page.
